# 체형 비교 — 남녀 평균 체형 3D 모형 (교육용 Android 앱)

성인 남성과 여성의 **평균적인 체형 차이**(성적 이형성)를 3D 마네킹 하나로 이어서 보여 주는 교육용 앱입니다.
재생 버튼을 누르거나 슬라이더를 움직이면 모형이 남성 평균 체형에서 여성 평균 체형으로 실시간으로 매끄럽게 바뀌고,
키·어깨너비·가슴둘레·허리둘레·엉덩이둘레가 함께 갱신됩니다.
머리 모양도 평범한 짧은 머리에서 어깨 아래까지 오는 파마 머리로 함께 바뀝니다.
여성 쪽 체형은 **개인차** 슬라이더로 평균에서 벗어난 범위(가슴 A~H컵, 더 가는 허리, 더 큰 엉덩이)까지 볼 수 있습니다.

- 설치 파일: [`dist/body-morph-1.2.apk`](dist/body-morph-1.2.apk) (약 3.5 MB, Android 8.0 이상)
- 완전 오프라인: 인터넷·권한을 전혀 쓰지 않습니다.
- 모형은 생식기 등 세부 구조를 생략한 석고 마네킹입니다.

## 설치

1. `dist/body-morph-1.2.apk`를 휴대폰으로 옮깁니다(GitHub에서 파일을 열고 **Download raw file**).
2. 파일을 열면 "출처를 알 수 없는 앱 설치" 허용을 묻습니다. 허용한 뒤 설치합니다.
3. 앱 이름은 **체형 비교**입니다.

## 화면

| 부분 | 기능 |
|---|---|
| 모형 | 한 손가락으로 돌리기, 두 손가락으로 확대·위아래 이동, 두 번 탭하면 처음 시점으로 |
| ▶ 재생 / 큰 슬라이더 | 남성 평균 ↔ 여성 평균을 연속으로 변화 |
| 치수 탭 | 키, 어깨너비, 가슴·허리·엉덩이둘레, 허리÷엉덩이 비율을 실시간 표시 (모형에서 직접 잰 값) |
| 요인별 탭 | **골격 / 지방 분포 / 근육량**을 따로 움직여 어떤 요인이 어떤 차이를 만드는지 확인. **머리 모양**(짧은 머리 → 긴 파마 머리)도 여기서 따로 조절 |
| 개인차 탭 | 여성 평균에 더하는 변형: **가슴** 평균(A컵)→H컵, **허리** 70→58 cm, **엉덩이** 97→109 cm. 남성 평균 쪽에서는 적용되지 않음 |
| 설명 탭 | 어깨·흉곽, 허리, 골반, 지방 분포, 근육, 목·후두, 키·손발, 얼굴형 — 고르면 해당 부위가 모형에 표시됨 |
| 치수선 · 머리카락 · 자동 회전 · 정면 | 키 눈금과 너비 안내선 켜고 끄기, 머리카락 숨기기(목·어깨를 볼 때), 회전, 정면 보기 |

## 모형에 대한 주의

- 사춘기에 성호르몬의 영향으로 몇 해에 걸쳐 생기는 차이를 **비교하기 쉽게 이어 붙인 시각화**입니다. 실제 몸이 변하는 과정이나 속도를 나타내지 않습니다.
- 수치(키 172.5/160.0 cm, 허리둘레, 체지방률 등)는 이해를 돕기 위한 **근사값·예시값**입니다. 연령·인구 집단·측정 방법에 따라 달라지며, 진단이나 평가에 쓸 수 없습니다.
- 남녀 각각의 분포는 넓고 서로 많이 겹칩니다. 평균과 다른 체형도 모두 정상입니다.
- 머리 모양은 몸의 차이가 아니라 꾸밈의 차이입니다. 변화를 알아보기 쉽게 넣은 것이며 끌 수 있습니다.
- **개인차** 탭의 값은 평균이 아닙니다. 컵 크기는 모형의 가슴둘레에서 밑가슴둘레를 뺀 값(A컵 10 cm부터 2.5 cm 간격)으로 붙였고, 세 값을 모두 끝까지 올린 조합은 실제로는 드문 체형입니다.

## 구조

```
body-morph/
├── web/              앱 화면 (HTML + WebGL). 브라우저에서 index.html을 열어도 그대로 동작
│   ├── index.html, style.css, app.js
│   └── mesh-data.js  tools/bake.mjs가 만든 모형 데이터 (직접 고치지 않음)
├── tools/bake.mjs    모형 생성기: 신체 치수 표 → 매끄러운 곡면 → 고정 위상 메시 + 요인별 변형량
├── android/          web/ 폴더를 그대로 담는 WebView 앱 (Java, 외부 라이브러리 없음)
└── dist/             빌드된 APK
```

모형은 `tools/bake.mjs` 맨 위의 치수 표(남성 값, 여성 값, 그 차이가 골격·지방·근육 중 어디서 오는지)로 정해집니다.
표를 고치고 다시 구우면 모형과 화면의 치수가 함께 바뀝니다. 개인차의 범위는 같은 파일의 `vary()`와 `BUST`에서, 머리 모양은 `buildHair()`에서 정합니다.

## 다시 빌드하기

```bash
node tools/bake.mjs                 # 모형 데이터 (Node 18+)
cd android && ./gradlew assembleRelease
# → android/app/build/outputs/apk/release/app-release.apk
```

JDK 17 이상과 Android SDK(platform 35, build-tools 35)가 필요합니다. SDK 위치는 `ANDROID_HOME` 또는 `android/local.properties`의 `sdk.dir`로 지정합니다.

`android/debug.keystore`는 **공개된 임시 서명 키**(Android 디버그 키와 같은 비밀번호)입니다. 다시 빌드한 APK를 기존 설치 위에 덮어쓸 수 있게 저장소에 넣어 두었습니다. 스토어에 올릴 때는 반드시 자신의 키로 바꾸세요.

## 확인한 범위

- 화면과 동작(재생, 슬라이더, 탭, 회전, 화면 크기별 배치)은 데스크톱 Chromium에서 확인했습니다. Android WebView도 같은 엔진 계열입니다.
- APK는 구조, 매니페스트(권한 없음, minSdk 26, targetSdk 35), 서명(v2), zipalign을 검증했습니다.
- **실제 기기나 에뮬레이터에서 실행해 보지는 못했습니다.** 기기에서 3D 화면이 뜨지 않으면 Android System WebView를 업데이트해 보세요.
