# 훅업 배관 VR 실습

반도체 FAB 훅업(Hook-up) 배관을 처음 하는 사람을 위한 VR 실습 시뮬레이터입니다.
현장 반장(박 선임)의 지시를 받으며 **PN2(공정용 질소) 라인 하나를 POC 밸브에서 장비 입구까지** 직접 연결하는 하루 작업을 그대로 해봅니다.

- VR 헤드셋(Meta Quest 등 WebXR 지원 브라우저)과 PC·모바일 브라우저 모두에서 동작
- 설치 없음: `index.html` 파일 하나 (Three.js는 CDN에서 불러옴)
- 반장 음성 안내(한국어 TTS), 힌트 화살표, 감점과 이유가 나오는 결과 보고서

## 실습 순서 (8단계)

| 단계 | 내용 |
|---|---|
| 1. 출근 · TBM | 작업허가서(PTW) 항목 확인, 화기작업 허가·질식 위험 퀴즈, 서명 |
| 2. 방진복 · 에어샤워 | 클린룸 착의 순서(위→아래), 반입 금지 물품 골라내기, 에어샤워 360° 회전 |
| 3. LOTO | 밸브 차단 → 자물쇠·꼬리표 → 잔압 제거 → 0 MPa 확인 |
| 4. 자재 · 절단 · 벤딩 | 316L EP 튜브 선택, 절단, 끝단 가공, N₂ 블로잉, 스프링백 고려한 90° 벤딩 |
| 5. 오비탈 용접 | 정렬, 아르곤 백퍼지(O₂ 기준), 용접 프로그램 선택, 비드 판정, 기록 + 비상대피 훈련 |
| 6. 설치 · 피팅 체결 | VCR 가스켓(신품)·1/8회전, 서포트, 튜브피팅 6시 마킹 → 1¼회전 → 갭 게이지 |
| 7. 기밀 · 헬륨 리크 | 가압 시험, He 리크 측정·판정, 불합격 연결부 재작업·재검사 |
| 8. 라벨 · LOTO 해제 · 정리 | 배관 표지·흐름 방향, 벤트 닫고 밸브 서서히 개방, 정리정돈, 작업 보고 |

메뉴에서 원하는 단계부터 바로 시작할 수 있습니다.

## 실행 방법

### PC · 모바일
`index.html`을 브라우저(Chrome, Edge, Safari)로 열면 됩니다. 인터넷 연결이 필요합니다(3D 라이브러리·글꼴을 CDN에서 받음).

### VR 헤드셋 (Meta Quest)
WebXR은 **HTTPS 주소**에서만 동작합니다.

1. 이 저장소에서 GitHub Pages를 켭니다: 저장소 **Settings → Pages → Source: Deploy from a branch → 브랜치 선택 → / (root)** → Save
2. 잠시 후 생기는 `https://<아이디>.github.io/<저장소>/` 주소를 Quest의 **Meta Quest 브라우저**로 엽니다.
3. **VR 헤드셋으로 시작**을 누릅니다.

(GitHub Pages 대신 Netlify 같은 아무 HTTPS 정적 호스팅에 `index.html`만 올려도 됩니다.)

## 조작

| | PC | 모바일 | VR |
|---|---|---|---|
| 둘러보기 | 마우스 드래그 | 화면 드래그 | 고개 돌리기 / 오른쪽 스틱(스냅 회전) |
| 이동 | `W` `A` `S` `D`, `Q` `E` 회전, 바닥 원 클릭 | 하단 방향 버튼, 바닥 원 탭 | 왼쪽 스틱, 바닥 원 가리키고 트리거 |
| 사용 | 클릭 | 탭 | 트리거 |
| 공구 작동 | 꾹 누르기 | 길게 누르기 | 트리거 누르고 있기 |
| 너트 조이기 | 누른 채 오른쪽으로 드래그 | 누른 채 오른쪽으로 드래그 | 트리거 누른 채 손목을 시계방향으로 |
| 작업 단말기 | 화면 오른쪽 패널 | 화면 아래 패널 | A/X 버튼 또는 그립으로 눈앞에 불러오기 |

## 주의

교육용 시뮬레이션입니다. 시험압력(0.77 MPa), He 리크 기준(1×10⁻⁹ atm·cc/s), 용접 퍼지 산소 기준(10 ppm) 등은 이해를 돕기 위한 **예시 값**이고, 착의 순서도 현장마다 다를 수 있습니다.
실제 작업은 반드시 현장의 시방서·작업절차서·안전교육과 관리자 지시를 따르세요. 등장하는 장비명(ETCH-07)과 인물은 가상입니다.
