# 별빛 질주 (Starlight Dash)

끝없이 이어지는 하늘길을 달리는 3D 무한 달리기 게임입니다. 차선을 바꾸고, 뛰고, 미끄러지고, 코너를 돌면서 별 코인을 모읍니다.
안드로이드 APK와 웹(브라우저) 양쪽에서 실행됩니다. 그래픽·소리는 전부 코드로 만들어서 외부 리소스나 인터넷 연결이 필요 없습니다.

## 설치 (안드로이드)

1. [`apk/starlight-dash.apk`](apk/starlight-dash.apk) 를 폰에 내려받습니다.
2. 파일을 열어 설치합니다. "출처를 알 수 없는 앱" 설치 허용을 물으면 허용합니다.
3. 안드로이드 7.0 이상에서 동작합니다. 요구 권한은 진동뿐이고, 인터넷 권한은 없습니다.

브라우저에서 해 보려면 `www/index.html` 을 열면 됩니다(키보드: 방향키 또는 WASD, 스페이스 = 점프).

## 조작

| 동작 | 터치 | 키보드 |
|---|---|---|
| 차선 바꾸기 / 코너에서 방향 전환 | 좌우 스와이프 | ← → |
| 점프 | 위로 스와이프 | ↑ / 스페이스 |
| 슬라이드 (공중에서는 빠른 착지) | 아래로 스와이프 | ↓ |
| 일시정지 | 화면 오른쪽 위 버튼, 뒤로 가기 | Esc / P |

코너가 가까워지면 정면 벽의 화살표 방향으로 스와이프해서 돕니다. 화살표가 양쪽이면 어느 쪽으로 돌아도 됩니다.

## 들어 있는 것

- **치트 모드** — 홈 화면·설정·일시정지 창에서 켭니다. 장애물을 부수고 지나가고, 끊긴 길 위를 걷고, 코너도 알아서 돌아서 쓰러지지 않고 끝없이 달립니다. 코인은 그대로 쌓이지만 최고 기록과 미션에는 반영되지 않습니다. 끝내려면 일시정지 → "그만하고 정산하기".
- **지형 6종** — 고요한 숲 → 노을 사막 → 얼음 설원 → 불의 화산 → 네온 시티 → 하늘 정원 순서로 바뀌며 반복됩니다. 오르막·내리막, 끊긴 길, 좁아지는 길, 갈림길이 나옵니다.
- **장애물** — 낮은 것(점프), 높은 것(슬라이드), 기둥(피하기)과 이들의 연속 배치. 멀리 갈수록 빨라지고 촘촘해집니다.
- **파워업** — 자석, 보호막, 부스터, 더블 코인.
- **상점** — 파워업 지속 시간과 점수 배율 강화(각 5단계), 부활의 별, 스타트 대시.
- **캐릭터 6종** — 루미(기본), 코코(자석 범위), 볼트(보호막 출발), 카게(점수 배율), 노바(부스터 지속), 드라코(무료 부활).
- **미션** — 3개씩 주어지고, 달성하면 코인 보상과 함께 더 어려운 미션으로 바뀝니다.

## 직접 빌드하기

```bash
# 1) 게임 번들 (src/ → www/)
npm install
npm run build

# 2) APK (안드로이드 SDK 필요: platforms;android-36, build-tools)
cd android
echo "sdk.dir=/path/to/android-sdk" > local.properties
./gradlew :app:assembleRelease
# 결과: android/app/build/outputs/apk/release/app-release.apk
```

## 폴더 구조

| 경로 | 내용 |
|---|---|
| `src/` | 게임 소스 (three.js, ES 모듈) |
| `src/track.js` | 길·장애물·코인 생성 |
| `src/game.js` | 이동, 충돌, 파워업, 카메라, 한 판의 흐름 |
| `src/biomes.js` | 지형별 색·장식·장애물 모양 |
| `src/character.js` | 캐릭터 모델과 애니메이션 |
| `src/ui.js`, `src/style.css` | 메뉴·상점·HUD |
| `www/` | 번들 결과물. 웹 배포본이자 APK 안에 들어가는 파일 |
| `android/` | WebView 로 `www/` 를 띄우는 안드로이드 앱 |
| `apk/` | 빌드된 APK |

## 참고

- `android/keystore/starlight-dash.jks` 는 사이드로드용 서명 키입니다. 다시 빌드해도 같은 서명이라 기존 설치 위에 덮어 설치됩니다. 스토어에 올릴 때는 비공개 키로 바꾸세요.
- 저장 데이터(코인, 강화, 기록)는 기기 안에만 저장됩니다. 설정 → "저장 데이터 초기화"로 지울 수 있습니다.
