# 집중 터치잠금 (Android)

휴대폰 화면을 **모니터·TV·VR로 미러링**하거나 **외부 화면(USB-C/HDMI, AR·VR 글래스)을 연결**하면
휴대폰 화면 터치를 자동으로 막아 주는 앱입니다. 연결을 끊거나 기능을 끄면 다시 터치할 수 있습니다.

화면 위에 투명한 막(접근성 오버레이)을 씌워 터치만 막으므로 미러링되는 화면 내용은 그대로입니다.

## 설치
1. `release/focus-lock.apk` 를 휴대폰으로 옮겨 설치 (출처를 알 수 없는 앱 설치 허용 필요)
2. 앱 실행 → **접근성 설정 열기** → 설치된 앱 → **집중 터치잠금** 켜기
   - Android 13+ 에서 회색으로 막히면: 앱 정보 → 오른쪽 위 ⋮ → **제한된 설정 허용** → 다시 켜기
3. (선택) 빠른 설정 편집에서 **터치 잠금** 타일 추가

## 잠기는 경우
| 상황 | 방식 |
|---|---|
| USB-C/HDMI 모니터, AR·VR 글래스, 스마트뷰·Miracast 무선 미러링 | 자동 (외부 디스플레이 감지) |
| 앱으로 화면 공유·캐스트 (Android 15+) | 자동 (화면 공유 감지) |
| VR 고글에 휴대폰을 끼우는 경우 등 | 앱의 **지금 잠금 / 10초 뒤 잠금**, 또는 타일 |

직접 잠글 때는 유지 시간(직접 끌 때까지 / 15·30·60·120분)을 고를 수 있습니다.

## 원격 조작도 막기 (VR 컨트롤러·손)
VR 등에서 휴대폰 화면을 띄워 놓고 조작하는 경우, 잠금 중에는 그쪽에서 휴대폰으로 보내는 입력도 막습니다
(설정 "VR 컨트롤러·손·키보드·게임패드 입력 막기", 기본 켜짐).

| 휴대폰에 들어오는 원격 입력 | 막힘 |
|---|---|
| 컨트롤러 트리거 클릭·손 핀치 → 휴대폰에 터치로 전달 | O |
| 마우스 포인터 클릭·스크롤 | O |
| 키보드·게임패드·컨트롤러 버튼 (볼륨·전원 제외) | O |
| 게임패드·컨트롤러 스틱, 휠 | O (Android 14+) |
| 헤드셋 자체의 컨트롤러·핸드트래킹 (VR 홈 메뉴, VR 앱 조작) | X — 휴대폰 앱이 헤드셋 시스템을 끌 수 없음 |

## 푸는 방법
- **볼륨 아래 버튼을 2초 안에 3번** (항상 동작)
- **두 손가락으로 3초 누르기** (설정에서 끌 수 있음)
- 외부 화면·공유 연결 끊기 (자동 잠금일 때)
- 유지 시간 종료, 앱의 **잠금 끄기**, 타일, 또는 접근성 서비스 끄기

연결 중에 직접 풀면 그 연결이 끊길 때까지는 다시 잠그지 않습니다(앱에서 "자동 잠금 다시 켜기" 가능).
화면을 끄면 잠금화면 PIN 입력은 막지 않고, 잠금화면을 푼 뒤 다시 잠깁니다.

## 한계
- 제스처 내비게이션의 가장자리 스와이프(홈·뒤로)는 기기에 따라 막히지 않을 수 있습니다. 3버튼 내비게이션은 막힙니다.
- 다른 앱 안에서 화면을 보내는 방식(Android 14 이하)이나 PC의 scrcpy 등은 자동 감지가 안 될 수 있어 수동 잠금을 쓰세요.
- 삼성 DeX에서 휴대폰을 터치패드로 쓸 때는 "외부 화면 연결 시 잠금"을 끄세요.

## 빌드
```bash
export ANDROID_HOME=<Android SDK 경로>   # 또는 local.properties 에 sdk.dir
./gradlew assembleRelease                 # → app/build/outputs/apk/release/app-release.apk
```
Java만 사용, 외부 라이브러리 없음. minSdk 26 (Android 8.0), targetSdk 35.
릴리스 APK는 빌드한 PC의 디버그 키로 서명되므로, 다른 PC에서 빌드한 APK로 업데이트하려면 기존 앱을 지우고 설치하세요.
