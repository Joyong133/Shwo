# 애니쉐도잉 – 일본 애니 명대사 따라읽기 (Android)

일본 애니메이션 명대사 **198개**를 원어민 음성으로 듣고, 따라 말하면 **발음 점수**를 매겨주는 안드로이드 앱입니다.

**APK 다운로드:** [`apk/AnimeShadowing-v1.0.apk`](../apk/AnimeShadowing-v1.0.apk) → 휴대폰에서 열어 설치 (출처를 알 수 없는 앱 설치 허용 필요)

## 기능
- 🔊 **듣기 / 🐢 천천히** – 일본어 TTS로 원어민 발음 재생, 속도 0.5x~1.5x 조절
- 🎤 **따라 말하기** – 일본어 음성 인식으로 내 발음을 듣고 0~100점 채점
  - 맞게 들린 글자는 초록, 안 들린 글자는 빨강으로 표시
  - 대사별 최고 점수 저장 (70점 이상 = 통과)
- **쉐도잉 모드** – 듣기가 끝나면 바로 마이크가 켜지고, 다음 대사로 넘기면 자동 재생
- 대사마다 **원문 · 히라가나 · 한글 발음 · 뜻** 표시 (각각 숨기기 가능 → 실력 테스트)
- 애니별 / 난이도별(초·중·고급) / 즐겨찾기 / 안 해본 대사 / 다시 연습 필터, 검색, 랜덤 연습

## 필요 조건
- Android 8.0 이상
- **일본어 음성(TTS)**: 설정 → 텍스트 음성 변환 → Google 음성 서비스 → 일본어 음성 설치 (앱이 없으면 안내 창이 뜸)
- **음성 인식**: Google 앱(음성 인식 서비스), 인터넷 연결, 마이크 권한

## 대사 추가하기
`tools/quotes_src.py`의 목록 **맨 끝에** 한 줄 추가 → `python3 tools/quotes_src.py` → 다시 빌드.
읽기(kana)는 실제 발음대로(조사 は→わ, を→お, へ→え) 적으면 한글 발음은 자동 생성됩니다.

## 빌드
```bash
cd anime-shadowing
echo "sdk.dir=/path/to/android-sdk" > local.properties
./gradlew assembleRelease        # → app/build/outputs/apk/release/app-release.apk
./gradlew testDebugUnitTest      # 한글 변환·채점·화면 스모크 테스트
```
`keystore/`의 서명 키는 개인 설치용입니다(같은 키로 서명해야 업데이트 설치가 됨). Play 스토어 배포용으로 쓰지 마세요.
