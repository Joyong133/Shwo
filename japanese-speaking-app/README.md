# 일본어 따라말하기 (Android 앱)

일본어 문장을 **듣고 → 따라 말하고 → 일치율(%)로 확인**하면서 기초부터 N1까지 실력을 올리는 앱입니다.

## 설치

1. 저장소의 [`apk/japanese-speaking.apk`](../apk/japanese-speaking.apk)를 휴대폰에서 내려받습니다.
2. 파일을 열고, "출처를 알 수 없는 앱 설치"를 허용하면 설치됩니다.
3. 처음 🎤를 누를 때 마이크 권한을 허용해 주세요.

- Android 8.0 이상
- 음성 인식에 **Google 앱**(기본 음성 인식)과 인터넷 연결이 필요합니다.
- 발음 듣기에는 일본어 TTS 음성이 필요합니다. 없으면 앱이 설치 화면으로 안내합니다.

## 사용법

1. 첫 화면에서 레벨(기초 N5 · N4 · N3 · N2 · N1)을 고르거나 **이어서 연습하기**를 누릅니다.
2. 문장이 후리가나·한국어 뜻과 함께 나오고, 원어민 발음이 자동으로 재생됩니다 (🔊 듣기 / 🐢 천천히 듣기).
3. 🎤를 누르고 문장을 따라 읽습니다.
4. 일치율이 나오고, 맞은 부분은 초록색 · 틀린 부분은 빨간색으로 표시됩니다.
5. **통과 기준(기본 80%) 이상이면 자동으로 다음 문장**으로 넘어갑니다. 못 넘으면 다시 도전하거나 건너뛸 수 있어요 (건너뛴 문장은 3문장 뒤에 다시 나옵니다).

## 실력이 오르도록 돕는 기능

- **레벨 추천**: 통과율 80% 미만인 가장 낮은 레벨을 "이어서 연습하기"로 추천
- **문장 순서**: 아직 통과 못 한 문장 먼저 → 통과한 문장은 점수 낮은 순으로 복습
- **약한 문장 복습**: 통과 못 했거나 최고점 90% 미만인 문장만 모아서 연습
- 문장별 최고 점수 · 시도 횟수, 오늘 통과 수, 연속 학습일 기록
- 설정(⚙): 통과 기준 60/70/80/90%, 자동 발음 듣기, 구글 음성 입력 창 사용, 기록 초기화

## 채점 방식

음성 인식 결과를 정답 문장과 글자 단위로 비교합니다(편집 거리).
한자 부분은 **한자 표기와 읽기(히라가나) 둘 다 정답**으로 인정하므로, 인식기가 「猫」를 「ねこ」로 적어도 감점되지 않습니다.
가타카나/히라가나, 전각/반각, 한자 숫자/아라비아 숫자(一度 = 1度), 문장부호 차이도 무시합니다.
인식기가 준 후보 여러 개 중 가장 높은 점수를 씁니다.

## 문장 추가·수정

`app/src/main/assets/sentences/n5.txt` ~ `n1.txt` (레벨당 30문장, 총 150문장)

```
[私|わたし]は[学生|がくせい]です。<TAB>저는 학생입니다.
```

- `[한자|읽기]`: 후리가나. `[家|いえ|うち]`처럼 읽기를 더 붙이면 그 읽기도 정답으로 인정합니다.
- 한 줄에 한 문장, 문장과 뜻은 탭으로 구분합니다. `#`으로 시작하는 줄은 주석입니다.

## 직접 빌드

```
cd japanese-speaking-app
./gradlew assembleRelease
# → app/build/outputs/apk/release/app-release.apk
```

Android SDK(API 35)와 JDK 17 이상이 필요합니다. 서명 키(`app/jpspeak.keystore`)는 개인 설치용으로 저장소에 포함되어 있어, 새 버전을 기존 앱 위에 덮어서 설치할 수 있습니다.
GitHub에 푸시하면 Actions가 APK를 빌드해 아티팩트로 올립니다.
